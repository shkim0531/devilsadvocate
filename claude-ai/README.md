# claude.ai에서 쓰기 (API·설치 없이)

프로그램을 설치하거나 API 키를 받지 않고, 지금 쓰는 claude.ai 구독 안에서 **녹취록 → 반론 리포트**를 만드는 방법입니다.
추가 비용이 없습니다. 구독 사용량 안에서 처리됩니다.

## 처음 한 번 설정 (5분)

1. claude.ai 왼쪽 메뉴 **프로젝트(Projects)** → **새 프로젝트** → 이름: `😈 악마의 변호인`
2. 프로젝트의 **지침(Instructions)** 을 열고 [`프로젝트_지침.md`](프로젝트_지침.md)의 내용을 전부 복사해 붙여 넣고 저장합니다.
3. (선택) **파일 추가**로 `회사맥락.txt`를 올립니다. 예시:
   ```
   직원 12명 소프트웨어 회사. 현금으로 약 9개월 운영 가능.
   올해 목표는 첫 기업 고객 5곳 확보. 정부지원사업 AI 바우처 신청 예정.
   ```
   회사 사정이 바뀌면 이 파일만 고치면 됩니다.

## 회의 때마다

1. 클로바노트 등에서 회의록을 **텍스트(.txt)로 내보냅니다**.
2. 프로젝트 안에서 새 대화를 열고 파일을 올린 뒤 한 줄만 적습니다.
   ```
   대표는 '김대표'. 매운맛으로.
   ```
   - 대표 화자를 안 적으면 Claude가 판단합니다.
   - .vtt/.srt 파일이 안 올라가면 확장자를 .txt로 바꾸거나 내용을 붙여 넣으면 됩니다.
3. 리포트가 나오면 필요한 부분을 복사해 공유합니다. 반론에 이견이 있으면 그 대화에서 바로 반박해 보세요.

## 프로그램 버전과 비교

| | claude.ai 프로젝트 (이 방식) | 프로그램 (API) |
|---|---|---|
| 설치·API 키 | 필요 없음 | Python 설치, API 키 필요 |
| 추가 비용 | 없음 (구독 사용량) | 사용량만큼 별도 결제 |
| 회의록 분석 | ○ | ○ |
| 실시간 회의 중 반론 | △ (🎤 버튼을 사람이 눌러야 함) | ○ (자동) |
| 결과 공유 | 복사·붙여넣기 | 마크다운 저장·인쇄 |

## 회의 중에 쓰기: 음성 입력 방식

claude.ai 앱의 **음성 입력(받아쓰기, 입력창의 🎤 버튼)** 으로 대표 발언을 받아 적어 보내면, 회의 도중에도 짧은 반론을 받을 수 있습니다.

1. 프로젝트를 하나 더 만듭니다: `😈 악마의 변호인 (회의 중)` → 지침에 [`실시간_프로젝트_지침.md`](실시간_프로젝트_지침.md)를 붙여 넣습니다. 회사맥락 파일도 같이 올립니다.
2. 회의마다 이 프로젝트에서 새 대화를 엽니다.
3. 대표가 결정·지시를 말할 때 🎤를 눌러 받아쓰고, 말이 끝나면 멈추고 보냅니다.
   - 답이 `👂`이면 결정이 아니라고 보고 기록만 한 것입니다.
   - 결정이면 6줄 안팎의 반론 카드가 옵니다.
4. 명령어
   - `메모: ...` 다른 참석자 말이나 배경 정보(반론 안 함)
   - `반박` 가장 최근 결정에 바로 반론
   - `순한맛` / `보통맛` / `매운맛` 강도 변경
   - `정리` 회의가 끝나면 전체 반론 리포트

**음성 모드(Claude가 소리 내어 대화하는 기능)는 쓰지 마세요.** 말이 멈출 때마다 Claude가 소리 내어 대답해 회의를 끊습니다. 소리가 나지 않는 **받아쓰기**를 쓰세요.

## 주의

- 회의 내용이 Anthropic으로 전송됩니다. 사내 보안 정책을 확인하고, claude.ai **설정 → 개인정보**에서 대화 데이터를 모델 개선에 쓰도록 허용했는지 확인하세요(회사 회의라면 꺼 두는 것을 권장).
- 참석자에게 녹음 사실을 미리 알리고 동의를 받는 것을 권장합니다.
- 반론은 판단 재료입니다. 최종 판단은 사람이 합니다.
